
# Student Management System

A Python application to manage student information and grades.

## Features

- Add new students
- View all students
- View top 3 students
- Calculate average grades
- Export students to CSV
- Import students from CSV
- Prevent duplicate student records during import

## Technologies

- Python
- CSV module
- Git and GitHub

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```

## Project Files

- `main.py` - Starts the application.
- `menu.py` - Displays the menu.
- `actions.py` - Contains student management functions.
- `students.csv` - Stores student information.
- `.gitignore` - Excludes unnecessary Python files.
